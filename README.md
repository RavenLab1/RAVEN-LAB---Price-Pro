# RAVEN LAB - حاسبة تسعير المطبوعات

ملف HTML واحد جاهز للنشر على GitHub Pages.

## الملفات

- `index.html` — الموقع الكامل: HTML + CSS + JavaScript داخل ملف واحد.

## طريقة الرفع السريعة على GitHub

1. أنشئ repository جديد في GitHub.
2. ارفع ملف `index.html` إلى جذر المشروع root.
3. افتح Settings ثم Pages.
4. من Build and deployment اختر Deploy from a branch.
5. اختر branch: `main` و folder: `/root` ثم Save.
6. بعد اكتمال النشر، سيظهر رابط الموقع في صفحة Pages.

## ملاحظات مهمة

- الموقع يعمل بدون backend.
- لأن الحسابات داخل JavaScript، أي شخص يستطيع رؤية المعادلات إذا كان الموقع عاماً.
- السعر النهائي يتم تأكيده من RavenLab بعد مراجعة الطلب.
